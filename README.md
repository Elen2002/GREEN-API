# GREEN-API Chat

Тестовое задание на позицию React фронтенд-разработчика. Веб-интерфейс чата для отправки и получения сообщений через сервис GREEN-API.

## Стек технологий

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Функционал

- Авторизация по учетным данным из личного кабинета GREEN-API (`idInstance`, `apiTokenInstance`)
- Валидация состояния инстанса при входе
- Создание диалога по номеру телефона получателя
- Отправка текстовых сообщений методом `SendMessage`
- Получение сообщений через HTTP API (`ReceiveNotification` + `DeleteNotification`)
- Список чатов с поиском, историей сообщений и счетчиком непрочитанных
- Сохранение сессии и истории в `localStorage`
- Демо-режим для быстрого ознакомления с интерфейсом

## Запуск проекта

### Требования
- Node.js 18+
- npm 9+

### Установка и запуск

1. Клонировать репозиторий:
```bash
git clone https://github.com/Elen2002/GREEN-API.git
cd GREEN-API
```

2. Установить зависимости:
```bash
npm install
```

3. Запустить режим разработки:
```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

### Сборка

```bash
npm run build
npm run preview
```
